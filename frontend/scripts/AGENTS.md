# Frontend Scripts Agent Instructions

## Owner

- `baldin_frontend`; use `baldin_full_stack_architect` for generated contract scripts.

## Scope

- Applies to frontend-local scripts and tooling helpers.

## Do

- Keep scripts reproducible from the repo-tracked env defaults.
- Preserve generated-schema ownership boundaries.

## Do Not

- Do not hand-edit generated outputs from scripts.
- Do not add hidden network or secret requirements.

## Validation

- Run script-specific checks only when requested.
- Report expected inputs and outputs.

## Handback Notes

- Call out generated artifact status.
