# Frontend Layout Agent Instructions

## Owner

- `baldin_frontend`.

## Scope

- Applies to app shells, layout components, navigation frames, and responsive structure.

## Do

- Preserve routing and accessibility landmarks.
- Keep responsive behavior intentional across desktop and mobile.

## Do Not

- Do not redesign global IA without explicit scope.
- Do not hide route contract changes inside layout edits.

## Validation

- Use focused layout or route checks when requested.
- Escalate if data or auth contracts are the blocker.

## Handback Notes

- Report affected shells, navigation, and responsive behavior.
