# CDK App Agent Instructions

## Owner

- `baldin_full_stack_architect`.

## Scope

- Applies to CDK application code.

## Do

- Keep stacks small and reviewable.
- Make configuration and secrets boundaries explicit.

## Do Not

- Do not hardcode real secrets or production-only assumptions.
- Do not add broad platform abstractions without explicit scope.

## Validation

- Use targeted CDK validation when requested.
- Escalate if runtime app behavior changes.

## Handback Notes

- Summarize stack/resource changes.
