# Choose Your Next Step

Use this page to choose the right next document for the work you are doing. Baldin is a private, local-first engineering monorepo for a developer-preview job-search automation workspace.

Use these docs for architecture, engineering workflow, and reference detail that sits below the top-level repository overview.

The sidebar is organized as a progression:

- **Start Here** for first orientation, setup, and deployment guidance
- **Explore Features** for product-level overviews of what Baldin does
- **Understand The System** for architecture and product boundaries
- **Build, Validate, Release** for day-to-day engineering workflow
- **Look Up Details** for reference material, resource links, and quick lookups
