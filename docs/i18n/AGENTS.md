# Docs I18n Agent Instructions

## Owner

- `baldin_full_stack_architect`.

## Scope

- Applies to Docusaurus localization files.

## Do

- Keep translations structurally aligned with source docs.
- Preserve frontmatter and route metadata semantics.

## Do Not

- Do not machine-translate large docs without review scope.
- Do not edit generated build output.

## Validation

- Run docs build when requested or when localization changes warrant it.
- Call out untranslated or intentionally deferred strings.

## Handback Notes

- Report locales and pages touched.
