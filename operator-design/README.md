
# Baldin OPERATOR Design

This directory is a standalone Vite bundle for the `operator-design` OPERATOR v2.1 contract.

It documents the language, route specimens, and design-system guidance for Baldin's current local-first job-search OS posture. Today Baldin is a private workspace for direction, ranked leads, applications, deliberate network reachability, private messaging as the shipped human loop, user-owned evidence, workflows, and agents. The product language stays centered on a career control plane where direction comes before tracking, any shared market truth remains secondary to private workflow, and automation remains grounded in inspectable evidence. The target direction is applicant-side observability later, but this bundle keeps that layer guarded, confidence-scoped, privacy-bounded, and clearly distinct from the shipped product. The visual contract in this bundle is intentional; use it as a design-reference surface, not as a source for frontend product-code changes.

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.
